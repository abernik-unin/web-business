# web-business

Izrada i održavanje web-stranica te razvoj poslovnih web-rješenja.

## Početno stanje

Repozitorij je početni prostor za planiranje, dokumentaciju i budući razvoj projekta.
Tehnologije i struktura projekta odredit će se u sljedećem koraku.

## Pravila sadržaja

- Ne dodavati lozinke, API ključeve ni druge osjetljive podatke.
- Ne pohranjivati studentske radove ni osobne podatke studenata.
- Za primjere koristiti sintetičke podatke i materijale za koje postoje odgovarajuća prava korištenja.
